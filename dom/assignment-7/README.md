# JavaScript Practice — Assignment 7

Each question includes a standalone ES6+ JavaScript file and a matching HTML runner.

## Running
Open the matching HTML file in a browser. All questions use core JavaScript, HTML, and CSS only; no frameworks.

## Questions
1. Product list manager — delegated edit/delete actions and outside-click auto-save
2. Character counter — 100-character limit, warning colors, reset
3. Multi-step form — validation, Next/Back, completion summary
4. Theme switcher — body class and data-theme attribute via setAttribute()
5. Image gallery — six images, modal preview and propagation handling
6. Student table — case-insensitive live filtering and empty state
7. Mouse logger — coordinates and double-click markers
8. Custom dropdown — outside-click close using capture phase
9. Form submit blocker — inline live errors and success message
