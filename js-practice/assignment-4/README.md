# JavaScript Practice — Assignment 4

Core JavaScript ES6+ solutions for the nine assignment questions. Each question has a separate `.js` file and, where browser interaction is needed, a matching HTML runner.

## Run
- Browser questions: open the matching HTML file in a browser. Use the page controls and inspect the console when noted.
- Console-only questions: open the HTML runner or run the JS file with Node.js.
- Q3 uses `prompt()` in its browser runner; for Node.js, replace the prompt line with a test ISBN string.
- Q2/Q5/Q7/Q8/Q9 use browser DOM forms.

## Questions
1. Product manager — classes, discount, filter
2. Student form validation — RegExp and visual validation states
3. Library management — issue/return methods and ISBN lookup
4. Dynamic form builder — generated fields and form data object
5. Movie booking — validation and booking details
6. Employee management — annual salaries, bonus, reduce payout
7. Login validation — specific RegExp error messages
8. Dynamic object updater — form updates object and DOM
9. Shopping cart — total and SAVE/ DISC percentage coupon

All examples use core JavaScript without frameworks.
