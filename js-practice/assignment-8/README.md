# Assignment 8 — JavaScript OOP and Array Methods

Each question has a standalone JavaScript solution and a matching HTML runner.

## Run
1. Open any `qN-*.html` file in a browser.
2. Open Developer Tools → Console to view the output.
3. Alternatively, run the matching JavaScript file with Node.js.

## Concepts covered
1. Student class, `reduce()`, average and grade calculation.
2. `map()`, `reduce()`, validation and try/catch.
3. Constructor functions, prototype methods and abstraction.
4. Class inheritance, method overriding and runtime polymorphism.
5. Inheritance, fare calculation and error handling.
6. `filter()`, `sort()`, `reduce()` and grouping by category.
7. Private class fields, deposits, withdrawals and exceptions.
8. Inheritance and the prototype chain.
9. `filter()`, `reduce()`, `map()` and empty-dataset validation.

All examples use sample data and log their results to the browser console.
