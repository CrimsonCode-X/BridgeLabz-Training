# Assignment 1 — Core JavaScript Practice

This folder contains one JavaScript file for each of the 10 assignment questions.

## Instructions
- Write each solution in its corresponding `.js` file.
- Use comments to explain your logic.
- Test programs in the browser console or with Node.js.
- Use descriptive variable names, consistent indentation, and readable formatting.
- Use core JavaScript only; no frameworks or libraries.

1. `q1-personalized-login-greeting.js` — Time-based greeting

5. `q5-weather-activity-planner.js` — Weather-based advice
6. `q6-progressive-discount-system.js` — Tiered shopping discount
7. `q7-smart-guessing-game.js` — Number-range guessing

9. `q9-random-math-quiz-generator.js` — Random arithmetic question
