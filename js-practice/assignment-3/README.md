# JavaScript Practice — Assignment 3

Ten standalone JavaScript solutions covering type conversion, validation, exceptions, strict mode, debugging, hoisting, closures, patterns, calculations, and JSON parsing.

## How to run
Open the matching HTML file in a browser, then open Developer Tools → Console. Each HTML file loads only its corresponding JS file. Q6 optionally prompts for a pyramid height; blank/Cancel uses 5.

## Questions
1. Dynamic Data Parser
2. Employee Bonus Calculator
3. Transaction Validator
4. Debugging Mystery
5. Hoisting Lab: The Sequence Trap
6. Pyramid Pattern Generator
7. Smart Calculator
8. Strict Mode Showdown
9. JSON Audit
10. Nested Hoisting and Closures

No external libraries are used.
